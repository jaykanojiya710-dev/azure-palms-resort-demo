# Azure Palms Resort & Spa — public demo

A static website preview built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Public demo behavior

- Room choices, dates, experiences, and prices are sample content for browsing.
- The booking flow is a preview only. It does not request personal details, create a reservation, or save information.
- Newsletter sign-ups are not sent or saved.
- Resort claims and contact details are examples. Verify and replace them before using this site for a real business.
- The original archive's environment file, local database, and booking API are excluded from this public demo.

## Build

```bash
npm run build
```

The static site is written to `out/` and can be hosted on GitHub Pages, Cloudflare Pages, or another static host.
